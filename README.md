# SSP 2024
All the code I wrote at the Summer Science Program 2024 at New Mexico State University! https://ssp.org/
- An orbital determination library and algorithm, implementing the Method of Gauss to determine the characteristics of asteroid 2012 FN62's orbit around the sun
- An orbital integration project to predict the asteroid's fate many years into the future
- Various side quests, including a Visual Python representation of the asteroid's orbit. (The white sphere is the asteroid, and the other spheres are the planets.)
